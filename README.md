# Power BI Practice Portfolio

**Status: Learning project**

A collection of Power BI assignments, sample workbooks, supporting documents, and compressed project materials. It demonstrates business-intelligence practice rather than a single automated application.

## Contents

- Power BI assignment archives such as `Assign 1.zip`, `Assign 3.zip`, and `Assignment8.zip`
- Game and sales-oriented project archives
- AdventureWorks sales material and supporting database files
- A project support document in DOCX format

## Focus Areas

- Dashboard and report development
- Business-facing sales analysis
- Working with sample relational data
- Power BI project organization and supporting documentation

## How To Explore

Use Power BI Desktop to open the extracted project materials. The repository does not include a single command-line entry point, automated test suite, or deployment configuration.

## Limitations and Future Improvements

The compressed files make automated review and reproducibility limited. Future improvements include adding screenshots, a catalog of reports and measures, data-source notes, refresh instructions, and documented DAX examples.
